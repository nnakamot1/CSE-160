Assignment 0 — Vector Operations
=================================

Open `src/asg0.html` in a browser (no server required).

A small 2D-canvas warmup: vectors are drawn as arrows from the canvas center
using a `Vector3` class (`lib/cuon-matrix-cse160.js`). Demonstrates basic
vector math — construction, addition, scaling, magnitude, and dot/cross
product — by drawing and combining vectors on screen.

Files
-----

- `src/asg0.html` / `src/asg0.js` — canvas setup and drawing logic.
- `lib/cuon-matrix-cse160.js` — course-provided `Vector3`/`Matrix4` library.
- `lib/vectorTests.html` — scratch page for testing vector operations.
